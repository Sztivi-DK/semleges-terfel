# Semleges Térfél

A CodeIgniter 4 practice project created during the Full Stack Developer course.

The project is a simple football-themed website built to practice:

- CodeIgniter 4 routing and controllers
- PHP views and reusable layouts
- Bootstrap
- Git branches and version control

## Branches

The repository contains multiple branches created while practicing Git branching.

The current working Bootstrap version is available on the `onlyBootstrap_ST` branch.

## Running locally

The project requires PHP 8.2 or newer and a local web server environment.

The application was tested locally with Apache and PHP 8.2.
